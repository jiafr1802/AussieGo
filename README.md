# AussieGo · 两周生活手帖

2026 年 10 月 26 日至 11 月 8 日的个人日程。沿用南欧十一日行程的方格纸、衬线标题、砖红与海蓝配色。

直接用浏览器打开 `index.html`，无需安装依赖或启动服务器。支持每日清单、添加/编辑/删除、分类与周筛选、每日机票记录、笔记、JSON 备份恢复和打印。

## 数据与隐私

- 事项和笔记存储在当前浏览器的 localStorage，不会同步到其他设备或浏览器。文件模式下的存储行为取决于浏览器，建议定期通过底部“备份”导出 JSON。
- 2026 年 10 月 25 日已通过 macOS Calendar 只读访问，取得与 10 月 26 日至 11 月 8 日相交的 10 条事件及其备注。网页保存本次快照，不会自动刷新，也不会写回日历；查询未展开区间外开始的循环事件。
- 5 条日历事件合并到已有事项的备注中，保留聊天确认的时间和名称；Apple 宣讲补入日历中的 19:00。携程已确认是 10 月 26 日 19:00 面试；校友会时段及全天跨日标记的差异在备注中保留。其余事件按覆盖日期加入，全天事件的结束日期按不包含当天处理。
- 已有勾选和每日笔记保留；版本更新仅执行一次，刷新不会重复导入，也不会恢复已删除的快照事项。
- 银行流水暂放 10 月 27 日，29 日为备选；周五聚会待定；签证申请暂建议 31 日处理，均可修改。
- 字体与图标通过 Google Fonts / unpkg 加载，需要联网；离线时仍有系统字体和按钮文字/无障碍标签，主要安排功能不依赖这些服务。

- 发布版本按要求将已知人名改为首字母，保留活动地点、时间与其他日程内容。首字母并不等于匿名或访问控制；公开网站仍可被其他人访问。未复制签证材料、个人证件或浏览器备份。

## GitHub Pages 部署

采用 GitHub Pages 的 Deploy from a branch，从 `master` 分支根目录发布，无需额外授权 Actions 工作流权限。此版本按用户要求处理人名后公开发布；公开源码仓库与站点均含行程、地点与日历快照。后续添加敏感内容前应检查发布范围。

1. 登录 GitHub，并确认本次更新可以公开。首次部署使用 GitHub 官方 CLI 的设备授权流程。
2. 将确认可发布的内容提交并推送到 GitHub 仓库。
3. 在仓库 Settings → Pages → Build and deployment 中，选择 Deploy from a branch，并指定 `master` / `/ (root)`。
4. 推送到该分支会自动发布，发布状态可在 Actions 或 Settings → Pages 查看。
5. 部署完成后，手机浏览器打开上方网站地址即可。

仓库仅提交网页资源、说明和配置，不上传浏览器备份或上级目录中的签证材料。`.nojekyll` 使 Pages 直接提供静态文件。`app.js` 本身包含个人日程与日历快照。

手机和电脑各自使用独立的浏览器存储。部署后仍需通过“备份 / 恢复”迁移现有勾选与笔记；GitHub Pages 不提供实时数据同步。
